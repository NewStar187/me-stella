# Me.Stella 게임 메카닉 결정 로그

* 최초 작성: 2026-08-27 (대화 세션 결정분 이관)
* 지위: PRD·커리큘럼 하위 문서. 학습 내용 충돌 시 커리큘럼 > PRD > 본 문서.
* 규율: 게임화 콘텐츠 창작은 제작자 몫. Claude 인스턴스는 구조 검토·공백 지적만 수행.
* 표기 규율: 난이도에 고등 등급 언어("3점급/4점급") 사용 금지.
수준 중립 루브릭(핵심 개념 수 / 조건 은닉 단계 / 해체 스텝 수)으로 표기한다.

## 1\. 확정 결정 (2026-08-27)

### 1.1 시스템 관할 3층 구조

|시스템|역할|계산|상태|
|-|-|-|-|
|A/B 전투|개념 적용 스캐폴딩. 마스터리 측정 아님|없음|확정|

|탑|심화·최난도 + 경쟁 + 계산의 거처|있음|후보(§3)|

### 1.2 D10 — 마스터리 측정 메커니즘 (답변됨)

* 마스터리 판정 = 단원 끝 대결계 관문 통과.
* 측정 대상 = 구조 독해·개념 연결 능력 (계산 수행 아님).
* 판정 결과 = ① 다음 단원(챕터) 해제 ② 해체 중 흔들린 개념·발문을 복습 큐 등록
(F-13 간격 반복과 연결).

### 1.3 D12 — 대결계 정의 (대부분 답변됨)

* 성격: 히든·도전 콘텐츠 → 전 단원 필수 관문으로 변경. 심화·최난도 역할은 탑으로 이관.
* 난이도: 최고난도 아님. "수포자에게 벽으로 느껴졌을 적당한 고난이도"를 해체하며
이해하는 경험. 목표 수준: 해당 단원 최상위 응용(수준 중립 루브릭으로 상세화 예정).
* 문제 구성 방법론: 하나의 복합 문제 = 핵심 개념 n개 + 하위 개념 조합 + 조건 은닉.
(모의고사식 제작 방법론의 수준 독립 적용 — 가설 H1)
* 플레이 형태: 계산 없이 조건 해석 → 조건별 개념 연결 → 단서 합성 → 답안 경로 구성.
다수 조건을 동시에 상대하는 감각 (A/B의 다중 동시 전투 확장형).
* 입력 형식: 단계 선택 + 경로 빈칸. (기존 빈칸추론형이 "계산 결과"를 빈칸으로 두는
것과 달리, 결과까지 가는 "경로"를 빈칸으로 둔다.) 서버 전용 채점 제약 충족 —
티어 3 상태 그래프의 노드 전이와 정합.
* 실패 프레임: 오답·원거리 개념 선택 시 "마법진 회로 과열" → 해당 개념 재정립 후
재도전. 실패를 서사 내 학습 행동으로 연결 (자존감 보호 원칙 정합).
* B 전투와의 급간: 핵심 개념 2개 이하(B) vs 다수 개념·실전형 은닉(대결계).
급간 적정성은 가설 H2로 등재.

### 1.4 D14 — 계산의 거처 / 제품 정체성 (확정)

* 필수 학습 루프(A/B 전투·대결계·복습)에 계산 없음.
* 제품 정체성: 수학에 대한 관심과 개념의 직관적 이해 — "문제를 보고 어떤 개념을
쓸지"의 직관 숙달. 문제 풀이(계산) 실력 향상은 목표가 아님.
* 계산의 유일한 거처 = 탑 (선택 콘텐츠, 후보 상태 — §3).
* 근거 기록: 제작자의 제품 철학 선택. ※ 설문은 "계산 피로" 명제를 측정하지 않았음
(측정된 것: 따라잡기 어려움 47.7% 1위, 오답 방치 61%, VOC 1위는 풀이·해설 요구).
본 결정의 근거를 설문으로 소급 인용하지 말 것.
* 파생 의무:

  1. PRD 개정 — 1.4 학습 목표, 2장 문제 정의, F-06 마스터리 의미 재작성
  2. 온보딩·마케팅에서 성적 향상 암시 문구 전면 금지
  3. "학생이 체감하는 진전" 대체 지표 정의를 W6 게임화 기획 필수 요구사항으로 등재
(리스크 근거: 학습앱 이탈 3위 = 실력 향상 체감 부재 15.1%)
  4. 대결계 v1.3 → v1.0 이동에 따른 로드맵 재배치 (M3 구간)
* \- Q1 확정 (2026-08-27) — PRD 1장 삽입용 문안:
* &#x20; "본 제품은 계산 능력의 향상을 약속하지 않는다. 계산과 암기는 학교 수업·학원·
* &#x20; 인강·자습에서 손으로 익히는 영역으로 남겨두며, 본 제품은 문제가 묻는 것을
* &#x20; 파악하고, 조건을 유효하게 해석할 개념을 찾고, 풀이의 순서를 설계하는 능력 —
* &#x20; 그 길찾기의 연습만을 담당한다."
* &#x20; 근거(제작자 판단): 흥미 상실의 주 지점은 개념이 아니라 풀이·계산 과정이라는 진단.
* &#x20; ※ "수학에서 계산을 없앤다" 프레임은 내부 전용 — 대외 카피 사용은 별도 검토
* &#x20; (Q16b-① 장벽 자극 리스크).

## 3\. 후보 시스템 T — 경쟁 탑 (2026-08-27 제안, 미확정)

제안 내용: 솔로 스토리와 별개의 도전 탑. 층수↑ = 개념 심화, 난이도는 개념 완전
이해·응용 수준. 계산 도입(필수 루프와 달리 계산 포함 — D14에 따라 계산의 유일한
거처). 힌트는 모범답안("답의 한 종류"로 표기)의 사용 개념 종류만 노출.
클리어 후 타 유저 풀이 리플레이 열람. 랭킹 1축 = 연산력 코스트(사용 마법진
개수·수준), 2축 = 유저 별점.

근거로 제시된 데이터: Q13 소셜+경쟁 합산 46.5%(중간), VOC 난이도·타인 풀이 요구.
→ 근거 한계: 소셜/경쟁 병합 수치, VOC는 정성 신호. 최종 데이터 재집계 전 인용 금지.

선결 조건 (전부 충족 전 확정 금지):

1. 최종 설문 데이터 사전등록 분석 재집계 (경쟁 단독 수치 분리) — 미충족
2. D10 (마스터리 측정 메커니즘) 결정 — ✅ 충족 (2026-08-27, §1.2)
3. D11 (동등 경로 동일 티어 여부) 결정 — 미충족, 코스트 랭킹과 직접 충돌
4. D12 (대결계 정의) 결정 — △ 부분 충족 (관할 경계 확정, 세부 e/f/g 미결)
5. OQ-04 (만 14세 정책) 결정 — 미충족, 소셜 기능의 전제
6. 범위 판정: v1 포함 vs v1.x 후치 (= D14-a, Gate 1 기획서에서 공수 대비 평가) — 미충족
7. 계산 입력·채점 형식 정의 — 미충족 (2026-08-27 계산 도입 결정에 따라 신설)

미해결 논점:

* "정답 없음" 메시지 vs 랭킹 서열화의 자기모순
* 별점의 인기투표 왜곡 (선점 효과·몰아주기)
* 랭킹 무결성 (재시도 정책 미정의)
* D14 이후 탑이 계산의 유일한 거처 — v1 제외 시 v1은 계산 0% 제품 (명시 수용 필요)
* UGC 운영 부담 (별점·닉네임 랭킹·리플레이 = 상시 모더레이션)

## 4\. 작업 가설 (검증 전 사실 취급 금지)

* H1: 복합 문제 제작 방법론(핵심 개념 조합 + 조건 은닉)은 학교급과 무관하게 적용
가능하다 — Gate 2 (콘텐츠 판정)에서 중등 저작 실전으로 검증.
* H2: B 전투 → 대결계의 난이도 급간은 적정하다 — 베타에서 대결계 실패율·이탈률로
검증. 판정 임계값은 베타 시작 전 사전 등록한다 (Gate 0 방식 준용).
