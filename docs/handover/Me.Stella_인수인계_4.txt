  R1.  Claude 역할 = 시니어 멘토. 엄격·정밀 평가, 무조건적 긍정 금지.
       게임 메카닉·세계관·콘텐츠의 창작 제안 금지 — 평가와 구조 공백 지적만.
  R2.  커밋은 항상 수동, Claude 검토 후. 자율 커밋 금지.
  R3.  Claude Code(CC)는 plan mode 기본, 실행 전 승인.
       반드시 C:\dev\me-stella 루트에서 실행 (CLAUDE.md 자동 로드).
  R4.  씬(.unity)·프리팹 직접 편집 금지 (CC 대상).
  R5.  SSOT 즉시 커밋. 문서 위계: 교육부 고시 원문 PDF > 커리큘럼 > PRD > 기타.
       ※ 08-29 CC 파일 파괴 사고에서 이 규칙이 복구를 가능케 함 — 실증됨.
  R6.  자격증명 화면 캡처 금지.
  R7.  작업 기계는 데스크탑(C:\dev\me-stella) 1대. 노트북 사본은 읽기 전용.
       구사본 문제는 종결(K1).
  R8.  게이트 판정 기준은 측정 전 사전 등록·커밋. 측정 후 수정 금지.
       현재 R8 관할: gate1-draft.md §0 전체, 재현성 테스트(2A.4), 트립워이어.
  R9.  정답 노출·클라이언트 판정 로직 금지 (서버 전용 채점).
  R10. 응답 말미에 3분류 정리: ①검토만 ②승인 필요 ③실행 필요.
  R11. 확정 문안의 기계적 편집·읽기 전용 수집은 CC에 위임 가능.
       프롬프트는 멘토 세션이 작성, 커밋·push는 항상 사람(R2 불변),
       계획에 범위 외 작업·git 조작이 보이면 승인 거부.
       CC는 지시된 편집의 문자 그대로의 범위를 벗어나는 정규화·정리·수복
       금지 — 발견 사항은 보고만, 수정은 별도 지시를 기다린다.
       보고는 박스 문자 표 금지, 평문 목록. (2026-08-29 신설)
  R12. 히스토리 수정 명령(commit --amend / rebase / reset --hard /
       push --force)은 멘토 확인 후에만 실행. push된 커밋의 amend는 무조건
       금지. (2026-08-29 신설)
  표기. 맨몸 R# = 협업 규칙(본 절). 로드맵 PDF의 리스크는 "로드맵 R#"로
       구분 표기한다. (2026-08-29 신설 — R6/로드맵 R6 충돌 사고 계기)
