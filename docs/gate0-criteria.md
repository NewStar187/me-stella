\## C. 모바일 브라우저 성능 (R10 — 최상위 리스크)

측정: iOS Safari + Android Chrome 실기, 각 60초 연속 조작

Go:      크래시 없음 + 조작 반응 지연 없음 + 화면 정상 표시

&#x20;        → 문제 풀이가 불편 없이 가능

Cond.Go: 문제 풀이는 완수 가능하나 지연·끊김이 체감됨.

&#x20;        단, 발생 지점이 일시적(초기 로딩·씬 전환)인 경우에 한함.

&#x20;        제출·입력 등 핵심 조작에서 반복 발생 시 No-Go로 판정한다.

No-Go:   크래시 발생, 또는 조작 불가 수준의 지연, 또는 화면 미표시

&#x20;        → 문제 풀이 자체가 성립하지 않음

기록 항목: 기기명·OS 버전·브라우저 버전 (OQ-06 최소 지원 사양 확정용)
